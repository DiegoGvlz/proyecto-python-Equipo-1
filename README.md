-¿Qué hace este proyecto?

Este proyecto utiliza Python para obtener información de Pokémon mediante una API y procesar los datos recibidos para facilitar su análisis. A partir de la información obtenida, se busca organizar y representar los datos mediante gráficas que permitan comparar diferentes características de los Pokémon, como sus tipos, pesos y alturas.


-API utilizada

La API con la que trabajamos es la siguiente: https://pokeapi.co/api/v2/pokemon/ 


-¿Cómo ejecutarlo?

Pasos para ejecutarlo:
1. Tener instalado Python
2. Instalar las siguientes dependencias: pip install requests matplotlib
3. Descargar este repositorio
4. Abrir una terminal en la carpeta del proyecto
5. Ejecutar el programa python main.py


-Graficas generadas 

1. Cantidad de Pokémon por tipo:
Representa la cantidad de Pokémon que pertenecen a cada tipo, permitiendo identificar cuáles son los más comunes. Se utiliza una gráfica de barras para facilitar la comparación.

2. Comparación de peso entre Pokémon:
Muestra las diferencias de peso entre los Pokémon consultados, permitiendo observar cuáles son más ligeros y cuáles tienen mayor peso.

3. Comparación de alturas entre Pokémon:
Representa las alturas de los Pokémon para visualizar sus diferencias de tamaño y facilitar la comparación entre ellos.

4. Estadisticas de Charizard:
Muestra las estadisticas base de charizard, permitiendo entender sus fortalezas.


-Lo que aprendimos

Durante el desarrollo de este proyecto aprendimos a trabajar con APIS para obtener información de manera automática, utilizar bibliotecas de Python como Requests y Matplotlib, y organizar el código mediante diferentes módulos. También reforzamos nuestros conocimientos sobre el procesamiento de datos y su representación mediante gráficas, además de aprender a utilizar GitHub para compartir y organizar nuestro trabajo.
